# Checklist de entrega ao cliente

## Antes do go-live

- [ ] Contrato, escopo do piloto, SLA e responsáveis aprovados.
- [ ] Controlador e operador de dados definidos para LGPD.
- [ ] Domínio, HTTPS e ambiente exclusivo configurados.
- [ ] Credenciais de demonstração substituídas.
- [ ] WhatsApp Business, número e webhook verificados.
- [ ] Base de conhecimento revisada pelo cliente.
- [ ] Regras de handoff, descontos e horários aprovadas.
- [ ] Modelos de mensagem e consentimento aprovados.
- [ ] Backup executado e restauração testada.
- [ ] Cenários de segurança e comportamento testados.

## Entrega

- [ ] URL da dashboard e utilizadores entregues por canal seguro.
- [ ] Formação de 45 minutos realizada.
- [ ] Manual rápido e canal de suporte compartilhados.
- [ ] Modo copiloto ativado inicialmente.
- [ ] Responsável humano disponível para handoffs.
- [ ] Métricas iniciais registadas para comparação.

## Primeira semana

- [ ] Rever diariamente conversas respondidas pela IA.
- [ ] Corrigir conhecimento insuficiente ou ambíguo.
- [ ] Medir tempo de resposta, handoff e conversão.
- [ ] Confirmar custos da Meta e do modelo.
- [ ] Aprovar a passagem gradual para autonomia segura.

## Encerramento do piloto

- [ ] Comparar resultados com a linha de base.
- [ ] Registar pedidos de melhoria e incidentes.
- [ ] Apresentar relatório ao cliente.
- [ ] Decidir continuidade, plano e limites mensais.
- [ ] Se não continuar, exportar e excluir dados conforme contrato.
